## 💡 Sobre o projeto

O **PRO Lidera Skills** oferece uma experiência interativa para quem deseja entender e desenvolver suas habilidades de liderança. O usuário responde a um teste de **18 perguntas**, cada uma com **4 alternativas** de pontuações específicas, e recebe um diagnóstico do seu perfil atual.

O resultado pode ser **baixado em PDF**, permitindo manter um registro da avaliação. Em etapas futuras, o sistema será integrado a uma **homepage de vendas online**, ampliando seu alcance e funcionalidades.

## 🧭 Como funciona

1. O usuário se cadastra na plataforma.
2. Responde às 18 perguntas do teste.
3. A soma das pontuações define o nível de liderança.
4. O resultado é exibido na tela e pode ser exportado em PDF.

### Níveis de liderança

| Nível | Descrição |
| :--- | :--- |
| 🔴 **Liderança frágil e pouco trabalhada** | Há bastante espaço para desenvolver competências básicas de liderança. |
| 🟡 **Liderança em desenvolvimento** | Boas bases já construídas, com pontos importantes a evoluir. |
| 🟢 **Líder de alta performance** | Perfil consolidado, com habilidades sólidas de liderança. |

## 🚀 Como executar

**Pré-requisitos:** [Node.js](https://nodejs.org/) e npm instalados.

```bash
# 1. Clone o repositório
git clone https://github.com/softexrecifepe/PI-PRO-LIDERA-TURMA-07-EQUIPE-02.git

# 2. Acesse a pasta do projeto
cd PI-PRO-LIDERA-TURMA-07-EQUIPE-02

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Depois, abra [http://localhost:3000](http://localhost:3000) no navegador.
